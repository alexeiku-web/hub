# Hub

A personal dashboard, installable as a phone app from GitHub Pages: today's workout, habit lines, projects with status and next steps, to-dos, other projects, and book and film lists.

- `index.html` is the app. The workout plan is built into it.
- `data.json` holds the project cards, habit lines, lists and any to-dos that are fine to be public. Editing this file and pushing updates the app the next time it opens.
- Ticks, items added in the app, pasted updates and uploaded files are stored on the phone only and never reach this repository.

This repository and the site are public. Keep names, work details and anything personal out of `data.json`; those go in through the app's "Paste an update from Claude" box.
